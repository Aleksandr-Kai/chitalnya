ВозможностиFeatures

📚 Библиотека из папки

📚 Library from a folder

Укажите папку с учебниками один раз: структура сохраняется в меню и на главном экране.

Pick your textbooks folder once: its structure is kept in the menu and on the home screen.

🖼 Обложки

🖼 Covers

Книги выглядят карточками с обложкой первой страницы, одинакового размера.

Books appear as equal-size cards with the first page as the cover.

🔖 Подписанные закладки

🔖 Labelled bookmarks

Сколько угодно закладок в книге, у каждой своя подпись, плюс общий список по всей библиотеке.

Any number per book, each with its own label, plus a library-wide list.

💾 Память

💾 Memory

Книга открывается там, где вы остановились. Масштаб помнится отдельно для каждой книги и для портрета и ландшафта.

A book opens where you stopped. Zoom is remembered per book, separately for portrait and landscape.

🎞 Лента превью

🎞 Thumbnail strip

Если справа есть свободное место, там лента страниц: текущая в рамке, тап переключает. Отключается в настройках.

When there is spare room on the right, a strip of pages: current one framed, tap to switch. Can be turned off.

💡 Экран не гаснет

💡 Screen stays on

Во время чтения экран не выключается, а системные панели можно скрыть.

The display never sleeps while you read, and system bars can be hidden.

Скачать и установитьDownload and install

Скачать Читальню (APK, 9 МБ)Download Chitalnya (APK, 9 MB)

Читальни нет в Google Play, поэтому она ставится из файла. Это безопасно и занимает минуту.Chitalnya is not on Google Play, so it installs from a file. It is safe and takes a minute.

Актуальная версия: Latest version:

  1. Скачайте файл Chitalnya.apk кнопкой выше прямо на планшете.
  2. Download Chitalnya.apk with the button above, right on the tablet.
  3. Откройте его: нажмите на уведомление о загрузке или найдите файл в папке «Загрузки».
  4. Open it: tap the download notification or find the file in the Downloads folder.
  5. Разрешите установку. Если Android спросит, включите «Разрешить установку из этого источника» для браузера или «Файлов», затем вернитесь назад.
  6. Allow the install. If Android asks, turn on “Allow from this source” for your browser or Files app, then go back.
  7. Нажмите «Установить». Если Play Защита предупредит о неизвестном приложении, выберите «Всё равно установить».
  8. Tap “Install”. If Play Protect warns about an unknown app, choose “Install anyway”.
  9. Откройте Читальню, зайдите в «Настройки» и выберите папку с учебниками.
  10. Open Chitalnya, go to Settings and pick your textbooks folder.

Нужен Android 8.0 или новее. Приложение только читает ваши файлы и не использует интернет. Обновление ставится поверх старой версии: закладки и страницы сохраняются.Requires Android 8.0 or newer. The app only reads your files and does not use the internet. Updates install over the old version and keep your bookmarks and pages.
